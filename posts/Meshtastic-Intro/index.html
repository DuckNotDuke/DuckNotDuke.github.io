Meshtastic - Decentralized Private Communication

29/06/2026

Meshtastic Overview

Meshtastic is a decentralized radio network that works by when one node gets a message, it rebroadcast it further, even if the message is encrypted. There for, the more people that join, the better it gets. A node can be quite inexpensive if you dont mind it connecting to an app/website on your phone or PC, which is adless and open source (and so is the meshtastic device itself, which is awsome). There is an app and website for both PC and Mobile

How big is the mesh?

I live in a pretty average city area, and I have so far detected 120 nodes, but there is definitely more. It is quite reliable with an okay antenna, especially in some areas.
